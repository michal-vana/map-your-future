# MAP YOUR FUTURE

Interaktivní kiosková aplikace MetLife pro roadshow: návštěvník odpoví na několik otázek o životním stylu a dostane vizuální vyhodnocení s MetLife sdělením, zatímco LED panel zobrazuje anonymní agregované statistiky všech účastníků.
Kompletní dokumentace je ve složce `docs/` (zadání a design) a v souboru `CLAUDE.md` v kořeni repozitáře.
